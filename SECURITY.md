# Security policy during development

NEXUS has no stable release or public network deployment support. It is
designed for one owner on loopback. Local Host, Origin and intent checks are
not remote authentication. The [security documentation](docs/security.md)
lists implemented controls and known limitations.

Please report a suspected vulnerability privately to the repository owner
through GitHub's private vulnerability reporting feature if enabled, or
another private channel already known to you. Avoid including private task
data in a report. There is no promised response timeline during development.
