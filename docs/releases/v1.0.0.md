# NEXUS v1.0.0 — Local AI Workflow Console

**Initial stable release • 18 November 2026 • Local-only / single-owner**

NEXUS provides a local-first, approval-controlled workflow for turning a task into a reviewed plan, running bounded tools, inspecting durable evidence and downloading sourced Markdown reports.

## Highlights

- **AI planning:** optional local Ollama model, with tested `qwen3.5:9b` execution; deterministic offline demo available.
- **Human control:** plan review and editing, scoped tool permissions, separate write/HTTPS approvals, pause/cancel and safe recovery.
- **Four allowlisted tools:** read selected text files, search selected local text, exact-approved public HTTPS text fetch and write sourced Markdown reports.
- **Evidence and history:** execution journal, receipts, source line references/hashes, verified downloads, report preview/comparison, JSON history export and opt-in retention.
- **Local experience:** React dashboard, task composer, execution cockpit, artifact library and Settings with dark/light appearance.
- **Reliability:** seven migrations, process-bounded worker, crash/write reconciliation, file/path containment and isolated backup-restore verification.

## Install and run (Windows)

Requirements: Python 3.12+, Node.js 22+, `uv`, npm.

From `services/api`, run `uv sync --extra dev` and `uv run alembic upgrade head`, start `uv run uvicorn app.main:app --host 127.0.0.1 --port 8765`, then start `uv run python -m app.worker` in a second terminal. From `apps/web`, run `npm ci` then `npm.cmd run dev` (PowerShell script policy may require `npm.cmd`). Open `http://127.0.0.1:5173`.

Follow [the local setup guide](https://github.com/Christopher-Doyle/NEXUS/blob/main/docs/development.md) and [user guide](https://github.com/Christopher-Doyle/NEXUS/blob/main/docs/user-guide.md) for details.

## Scope and security notes

- **Local-only:** not a hosted multi-user service, remote authentication system or unrestricted computer agent. No general shell execution; file inputs are bounded to selected/approved scopes.
- An **owner-approved temporary development-tool exception** applies **only** to `picomatch` [GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf) in the exact locked Vite/Vitest development tree. It is **not fixed**; exception ends **18 December 2026**, with other high/critical findings blocked and a separate production-dependency audit enforced.
- A residual same-OS-user report-directory race is accepted only for trusted local single-owner use; this does not protect against hostile same-user processes or malware.
- Deleted SQLite records and local files are **not securely erased** from WAL, backups or snapshots.
- Evidence-based reports contain cited excerpts rather than arbitrary LLM-authored claims. External access requires separate exact approval.
- Automated accessibility checks and owner-reported Narrator/keyboard and responsive emulation tests do not constitute independent accessibility certification.

See the [security audit](https://github.com/Christopher-Doyle/NEXUS/blob/main/docs/security-audit.md), [v1 requirement matrix](https://github.com/Christopher-Doyle/NEXUS/blob/main/docs/v1-requirement-matrix.md) and [release policy](https://github.com/Christopher-Doyle/NEXUS/blob/main/docs/release-policy.md).
